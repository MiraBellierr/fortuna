# Surface brief — resources/views/welcome.blade.php (front page)

Scope: the signed-out front page only. Visitor mode: Persuade.

Audience/job/action/proof:
- Visitor: an individual looking for a personal expense tracker.
- Job: understand in seconds what Fortuna does and take the one action — create an account (register), with log in as the return path.
- Proof: product truth only. Built features (dashboard stats & charts, category colors, filtering, receipts, budget overshoot alerts) and the built system can be shown as a specimen; no testimonials, no user counts, no benchmarks. Roadmap items (CSV/PDF export, mobile quick-entry) may appear as announced "notices", never as shipped claims. Existing tagline stays: Master Your Money.
- Constraints: light theme committed (no dark variants); currency display MYR; single-user privacy is product truth.

Chosen direction: Swiss Light — Minimalist Swiss typographic system: clean 12-column grids on near-white ground, generous whitespace, neutral grays, one strong accent, a single grotesque family, hairline rules instead of cards and shadows. Clarity and trust through stable, flat, precise composition. The specimen ledger table (with one overshoot flagged in the accent) is the honest demonstration.

Unresolved decisions: none blocking.

## Direction contract

THESIS: A front page that behaves like a Swiss typographic report: flat, gridded, unhurried, and precise; it refuses the hero-over-card-row conversion template by running flush-left display type against hairline-ruled columns and an inset data table.

OWN-WORLD: Near-white ground (#FAFAF8), pure ink text (#111111), neutral gray secondary text (#6E6E6E), hairline rules (#E4E4E2), one strong signal accent (#E3000F) reserved for the primary action, overshoot flags, and focus; Archivo atlas as the only type family (400/500/600/700); sharp corners, no shadows, no glass; tabular numerals in data.

STORY: The visitor understands this is a precise, private expense ledger that reports honestly; believes the numbers are presented straight; acts by creating an account (or logs in).

FIRST VIEWPORT: Top bar with wordmark left and log-in + solid primary button right; below, a 12-column band: left 8 columns hold a flush-left two-line display headline, a 60ch gray deck, and the two actions (solid accent "Create your account", quiet text "Log in"); right 4 columns hold the specimen ledger table — hairline-ruled, tabular numerals, one overshoot row flagged in the accent, marked Specimen. Much whitespace below before the first section rule.
